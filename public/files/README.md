# Downloadable files

Put files that visitors should be able to download or play here, then link to
them from a content file with a site-relative path, for example:

    /files/pakawat-poldetch-cv.pdf
    /files/h1-neuron-report.pdf
    /files/shrimppulse-demo.mp4
    /files/guitar-recital-2026.mp3

Photographs do not go here. They belong in `src/assets/images/` so that the
site can optimise them (see the README there).
